
# 🩸 Labirent: Ölümcül Kalış

**Karanlıktan kaç. Labirenti keşfet. Hayatta kal.**

Labirent: Ölümcül Kalış, oyuncuların tehlikeli ve gizemli bir labirentte hayatta kalmaya çalıştığı, birinci şahıs kameralı 3D korku oyunudur.

## 🎮 Özellikler

- 🌐 Çevrim içi çok oyunculu oyun hedefi
- 🏚️ Karanlık ve gizemli 3D labirent
- 👁️ Birinci şahıs kamera
- 😱 Korku atmosferi ve gerilim
- 📱 Telefonlar için dokunmatik kontroller
- 🖥️ Bilgisayarlar için klavye ve fare kontrolleri
- 🎨 Gerçekçi grafikler için geliştirme hedefi
- 🧭 Keşif, kaçış ve hayatta kalma mekanikleri

## 🕹️ Platformlar

- Android ve diğer uyumlu mobil tarayıcılar
- Windows, Linux ve macOS tarayıcıları

## 🚀 Nasıl Oynanır?

1. Oyunun GitHub Pages bağlantısını aç.
2. Oyunun yüklenmesini bekle.
3. Kontrolleri kullanarak labirenti keşfet.
4. Tehlikelere dikkat et ve çıkış yolunu bul.

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- WebGL / Three.js
- GitHub Pages

## 🌍 Yayınlama

Bu proje GitHub Pages üzerinden yayınlanmak üzere tasarlanmaktadır.

GitHub deposunda **Settings → Pages** bölümüne gir ve yayın kaynağı olarak `main` dalını ve `/ (root)` klasörünü seç.

## 📌 Geliştirme Durumu

Proje geliştirme aşamasındadır. Çevrim içi çok oyunculu sistem, gerçek zamanlı oyuncu senkronizasyonu ve diğer özellikler kullanılan altyapıya göre ayrıca uygulanmalıdır.
